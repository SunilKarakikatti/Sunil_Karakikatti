Projects

BoothLess Toll Collection System
The BoothLess Toll Collection System is a smart highway toll automation project designed to reduce traffic congestion and enable seamless cashless travel. The system uses GPS geofencing and RFID technology to automatically detect vehicles when they enter toll zones. AI-powered vehicle detection is integrated to identify different types of vehicles and ensure accurate toll calculation. Once the vehicle is verified, the toll amount is deducted automatically without requiring the vehicle to stop at the toll booth. This project improves transportation efficiency, saves travel time, reduces fuel consumption, and supports future smart-city transportation solutions.
Python / C++ RFID GPS
Food Ordering System
The Food Ordering System is a voice-enabled web application designed to simplify the online food ordering experience for users. The application allows customers to browse restaurants, place food orders, and track deliveries through a responsive and user-friendly interface built with React.js. Voice AI functionality is integrated to enable hands-free food ordering, making the system more accessible and convenient. The backend manages order processing, restaurant integration, and delivery tracking efficiently using Python and MySQL. This project focuses on improving user experience, automating food ordering processes, and providing a modern digital solution for restaurant and delivery management.
